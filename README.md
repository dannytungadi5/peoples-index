# peoples-index
The tokenized-stock index the community picks, priced with proof. Base Stocks Maxxing - Meme and Community Economies track.


375 pool records scanned; 82 verified and priced on-chain (snapshot coverage).

Two primary public Base RPC endpoints (mainnet.base.org and publicnode) are compared byte-for-byte. A third endpoint (BlastAPI) replaces one primary only after a transport failure; it is not a third vote. Two matching responses are required; a mismatch or only one usable response hides the value.

X polls are public but not on-chain and are not Sybil-resistant. Multiple accounts or coordinated brigading can distort a result; this prototype does not verify one person per vote and cannot reliably filter new accounts or follower counts. Publish the poll URL, closing time, result screenshot and any observed manipulation with each rebalance. Do not describe a poll as representative of all holders or of the wider community.
